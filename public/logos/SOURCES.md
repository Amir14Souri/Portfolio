# Skill logo sources

These assets identify the corresponding tools; the original projects retain
their logos and trademarks. Files are served locally for the static export.

Raster logos are resized for their displayed dimensions. Large SVGs that
contained embedded bitmaps or extensive paths use a transparent 192 px
PNG inside an SVG wrapper, preserving their URLs and CSS mask behavior.
Colors and silhouettes retain the source appearance. Small skill PNGs
are capped at 64 px for their 16 px display size.

Hugging Face libraries use the [Hugging Face mark](https://huggingface.co/brand).
TorchVision uses the [PyTorch mark, as its documentation does](https://docs.pytorch.org/vision/stable/index.html).
Generic SQL uses a neutral database glyph rather than a MySQL brand mark.

Single-color marks use the palettes documented by
[Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/data/simple-icons.json).
Corrected palettes include [Django](https://www.djangoproject.com/community/logos/),
[GitLab](https://about.gitlab.com/press/press-kit/),
[Git](https://git-scm.com/community/logos), [R](https://www.r-project.org/logo/),
and Nginx. Brand colors are not blended for theme contrast; the readable skill
labels remain independent of these decorative marks. Monochrome brands adapt
to the theme. Desktop category hover reveals original colors; touch shows
original colors immediately.
